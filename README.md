# 🚀 INC 5000 Companies Data Analysis - Power BI Project

![Dashboard Preview](https://github.com/gamal1osama/Dashboard-5000-Companies/blob/master/dashboard1.jpg)

## 📂 Project Overview
This Power BI project analyzes the [INC 5000 Companies Dataset](https://www.kaggle.com/datasets/mysarahmadbhat/inc-5000-companies) to uncover insights about high-growth companies in 2019. The dashboard addresses key business questions through interactive visualizations.

## 📊 Dataset Overview
**Fields Included**:
- `Company` name, industry, founding year, website, and location
- `2019 revenue`, `📈 % growth`, `👥 YoY worker count`
- `Number of years` on the INC 5000 list

## 🔍 Analysis Questions Addressed
1.  What's the average revenue? (Broken down by industry)
2.  Most/least represented industries
3.  Geographic trends
4.  Industries with largest growth rates
5.  Companies with staff increases
6.  Revenue growth with staff reduction

## ✨ Key Features
- `Interactive filters` for industry/location
- `Visualization types`: Maps, treemaps, sparklines
- `Dynamic calculations` for growth metrics
- ` obile-responsive design`
